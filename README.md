## Tier 1 — Foundation (P01–P20)

Focus: C syntax, input/output, conditions, loops, functions, arrays, strings, and elementary mathematics.

### P01 — Sum of a Number Stream

- **Difficulty:** 1/10
- **Concepts:** loops, integer input, accumulation, `long long`
- **Problem:** Read `N` integers and calculate their sum. The values may be negative, so do not initialise the answer in a way that assumes all values are positive.
- **Input:** First line: integer `N`. Second line: `N` space-separated integers.
- **Output:** One integer — the sum.
- **Constraints:** `1 <= N <= 200000`; `-10^9 <= A[i] <= 10^9`.
- **Sample 1:** Input `5` then `2 -4 7 1 3`; output `9`.
- **Sample 2:** Input `3` then `-8 -2 -5`; output `-15`.
- **Target complexity:** Time `O(N)`; extra space `O(1)`.
- **Skill tested:** Correct accumulation and selecting a type large enough for the maximum possible sum.

### P02 — Progressive Electricity Bill

- **Difficulty:** 2/10
- **Concepts:** conditions, piecewise calculations, arithmetic
- **Problem:** A household pays a progressive energy charge: the first 100 units cost 1 currency unit each, units 101–200 cost 2 each, and every unit above 200 costs 3 each. Calculate the bill. The rate applies only to units inside its own slab; it is not a flat rate applied to all units.
- **Input:** One integer `U`, the number of units consumed.
- **Output:** One integer — the total bill.
- **Constraints:** `0 <= U <= 10^9`.
- **Sample 1:** Input `250`; output `450`.
- **Sample 2:** Input `80`; output `80`.
- **Target complexity:** Time `O(1)`; extra space `O(1)`.
- **Skill tested:** Translating a piecewise rule into mutually exclusive conditions.

### P03 — Minutes Between Two Clock Times

- **Difficulty:** 2/10
- **Concepts:** integer arithmetic, modulo, time conversion
- **Problem:** Given a start time and an end time in 24-hour `HH:MM` format, find the number of minutes elapsed when the end time is on the same day or the immediately following day. If the end time is earlier than the start time, assume midnight was crossed. The two times are never equal.
- **Input:** Two lines, each containing a valid time in `HH:MM` format.
- **Output:** One integer — elapsed minutes.
- **Constraints:** Hours `00–23`; minutes `00–59`.
- **Sample 1:** Input `23:50` and `00:20`; output `30`.
- **Sample 2:** Input `09:10` and `10:00`; output `50`.
- **Target complexity:** Time `O(1)`; extra space `O(1)`.
- **Skill tested:** Converting structured input into a single numeric representation.

### P04 — Days in a Given Month

- **Difficulty:** 2/10
- **Concepts:** conditions, leap years, calendar rules
- **Problem:** Given a year and month, print the number of days in that month in the Gregorian calendar. A year is a leap year if it is divisible by 400, or if it is divisible by 4 but not by 100.
- **Input:** Two integers `Y M` where `M` is the month number.
- **Output:** One integer — the number of days in the month.
- **Constraints:** `1 <= Y <= 10^9`; `1 <= M <= 12`.
- **Sample 1:** Input `2000 2`; output `29`.
- **Sample 2:** Input `1900 2`; output `28`.
- **Target complexity:** Time `O(1)`; extra space `O(1)`.
- **Skill tested:** Handling nested conditions and century edge cases.

### P05 — GCD and LCM Pair

- **Difficulty:** 3/10
- **Concepts:** Euclidean algorithm, loops, overflow awareness
- **Problem:** For two non-negative integers, print their greatest common divisor and least common multiple. Define the LCM as zero if either input is zero. Otherwise calculate it using a division-before-multiplication order to reduce overflow risk.
- **Input:** Two integers `A B`.
- **Output:** Two space-separated integers: `GCD LCM`.
- **Constraints:** `0 <= A,B <= 10^9`; the LCM fits in signed 64-bit integer range.
- **Sample 1:** Input `18 24`; output `6 72`.
- **Sample 2:** Input `7 13`; output `1 91`.
- **Target complexity:** Time `O(log(min(A,B)))`; extra space `O(1)`.
- **Skill tested:** Implementing a reusable mathematical function and handling zero correctly.

### P06 — Count Primes in an Interval

- **Difficulty:** 3/10
- **Concepts:** primality testing, loops, square root bound
- **Problem:** Count the prime integers in the inclusive interval `[L,R]`. A prime is an integer greater than 1 with exactly two positive divisors. Use an approach suitable for the stated upper bound; do not test divisors all the way to `R` for every candidate.
- **Input:** Two integers `L R`.
- **Output:** One integer — the number of primes in the interval.
- **Constraints:** `1 <= L <= R <= 10^6`.
- **Sample 1:** Input `10 20`; output `4`.
- **Sample 2:** Input `1 5`; output `3`.
- **Target complexity:** Time `O(R log log R)` with a sieve; extra space `O(R)`.
- **Skill tested:** Building a sieve, marking composites from `p*p`, and excluding 1 from the prime set.

### P07 — Perfect Square Detector

- **Difficulty:** 2/10
- **Concepts:** loops or integer square root, boundary checking
- **Problem:** Determine whether a non-negative integer is a perfect square. Avoid relying on floating-point equality alone; a robust solution must handle values near the maximum constraint.
- **Input:** One integer `N`.
- **Output:** Print `YES` if `N` is a perfect square; otherwise print `NO`.
- **Constraints:** `0 <= N <= 10^18`.
- **Sample 1:** Input `49`; output `YES`.
- **Sample 2:** Input `50`; output `NO`.
- **Target complexity:** Time `O(log N)` using integer binary search; extra space `O(1)`.
- **Skill tested:** Binary search on an answer and safe multiplication/comparison.

### P08 — Digit Statistics

- **Difficulty:** 2/10
- **Concepts:** modulo, integer division, loops
- **Problem:** For a non-negative integer, calculate the sum of its decimal digits and the number of digits. Treat `0` as a one-digit number whose digit sum is zero.
- **Input:** One non-negative integer `N`.
- **Output:** Two integers: digit sum and digit count.
- **Constraints:** `0 <= N <= 10^18`.
- **Sample 1:** Input `5082`; output `15 4`.
- **Sample 2:** Input `0`; output `0 1`.
- **Target complexity:** Time `O(number of digits)`; extra space `O(1)`.
- **Skill tested:** Extracting digits safely and handling the special case zero.

### P09 — Reverse a Signed 32-bit Integer

- **Difficulty:** 3/10
- **Concepts:** digit extraction, signed integers, overflow
- **Problem:** Reverse the decimal digits of a signed 32-bit integer while preserving its sign. Leading zeroes in the reversed result disappear. If the mathematical reversed value is outside the signed 32-bit range `[-2147483648,2147483647]`, print `OVERFLOW`.
- **Input:** One signed 32-bit integer `X`.
- **Output:** The reversed integer, or `OVERFLOW`.
- **Constraints:** `-2147483648 <= X <= 2147483647`.
- **Sample 1:** Input `-120`; output `-21`.
- **Sample 2:** Input `1534236469`; output `OVERFLOW`.
- **Target complexity:** Time `O(number of digits)`; extra space `O(1)`.
- **Skill tested:** Guarding arithmetic before it overflows.

### P10 — Numeric Palindrome

- **Difficulty:** 2/10
- **Concepts:** digit reversal, conditions
- **Problem:** A non-negative integer is a palindrome if its decimal representation reads identically from left to right and right to left. Print whether the given number is a palindrome. Do not convert the number to a string.
- **Input:** One integer `N`.
- **Output:** `YES` or `NO`.
- **Constraints:** `0 <= N <= 10^18`.
- **Sample 1:** Input `12321`; output `YES`.
- **Sample 2:** Input `120`; output `NO`.
- **Target complexity:** Time `O(number of digits)`; extra space `O(1)`.
- **Skill tested:** Numeric digit manipulation.

### P11 — Three-Digit Armstrong Number

- **Difficulty:** 2/10
- **Concepts:** loops, digit extraction, arithmetic
- **Problem:** A three-digit number is an Armstrong number if the sum of the cubes of its digits equals the number itself. Determine whether the input is a three-digit Armstrong number. Values outside the three-digit range must return `NO`.
- **Input:** One integer `N`.
- **Output:** `YES` or `NO`.
- **Constraints:** `-10^6 <= N <= 10^6`.
- **Sample 1:** Input `153`; output `YES`.
- **Sample 2:** Input `154`; output `NO`.
- **Target complexity:** Time `O(1)`; extra space `O(1)`.
- **Skill tested:** Applying a precise mathematical definition in code.

### P12 — Nth Fibonacci Number

- **Difficulty:** 3/10
- **Concepts:** iteration, recurrence, 64-bit integers
- **Problem:** Print `F(N)` where `F(0)=0`, `F(1)=1`, and `F(N)=F(N-1)+F(N-2)`. Use an iterative solution rather than naive recursion.
- **Input:** One integer `N`.
- **Output:** One integer — `F(N)`.
- **Constraints:** `0 <= N <= 92`; the answer fits in an unsigned 64-bit integer.
- **Sample 1:** Input `10`; output `55`.
- **Sample 2:** Input `0`; output `0`.
- **Target complexity:** Time `O(N)`; extra space `O(1)`.
- **Skill tested:** Translating a recurrence into an iterative implementation.

### P13 — Convert Decimal to Binary

- **Difficulty:** 2/10
- **Concepts:** division, remainder, arrays or character buffers
- **Problem:** Convert a non-negative decimal integer to its binary representation without using library conversion functions. Print `0` for zero and do not print leading zeroes for other values.
- **Input:** One integer `N`.
- **Output:** Its binary representation as a sequence of `0` and `1` characters.
- **Constraints:** `0 <= N <= 10^18`.
- **Sample 1:** Input `13`; output `1101`.
- **Sample 2:** Input `0`; output `0`.
- **Target complexity:** Time `O(log N)`; extra space `O(log N)` for the output buffer.
- **Skill tested:** Reversing a generated sequence and managing character arrays.

### P14 — Second-Largest Distinct Element

- **Difficulty:** 3/10
- **Concepts:** arrays, traversal, duplicate handling
- **Problem:** Find the second-largest **distinct** value in an array. If fewer than two distinct values exist, print `-1`. Do not sort the array.
- **Input:** First line `N`; second line contains `N` integers.
- **Output:** The second-largest distinct value, or `-1` if it does not exist.
- **Constraints:** `2 <= N <= 200000`; `-10^9 <= A[i] <= 10^9`.
- **Sample 1:** Input `5` then `4 1 7 7 3`; output `4`.
- **Sample 2:** Input `4` then `5 5 5 5`; output `-1`.
- **Target complexity:** Time `O(N)`; extra space `O(1)`.
- **Skill tested:** Maintaining multiple candidates without confusing duplicates.

### P15 — Left-Rotate an Array

- **Difficulty:** 3/10
- **Concepts:** arrays, modulo, reversal technique
- **Problem:** Rotate an array left by `K` positions. `K` may be larger than `N`; rotating by `N` or any multiple of `N` leaves the array unchanged.
- **Input:** First line `N K`; second line contains `N` integers.
- **Output:** The rotated array on one line, space-separated.
- **Constraints:** `1 <= N <= 200000`; `0 <= K <= 10^18`; `|A[i]| <= 10^9`.
- **Sample 1:** Input `5 2` then `1 2 3 4 5`; output `3 4 5 1 2`.
- **Sample 2:** Input `4 5` then `10 20 30 40`; output `20 30 40 10`.
- **Target complexity:** Time `O(N)`; extra space `O(1)` beyond the array.
- **Skill tested:** Normalising rotations and implementing in-place array transformations.

### P16 — Majority Element Candidate

## Tier 4 — Beyond CodeVita (P61–P80)

Focus: Fenwick trees, segment trees, lazy propagation, sparse tables, advanced graph algorithms, bitmask DP, digit DP, offline queries, order statistics, geometry, and heavy-light decomposition. These are stretch problems; do not prioritise them over Tier 1–3 before the immediate test.

### P61 — Fenwick Tree: Point Updates and Range Sums

- **Difficulty:** 7/10
- **Concepts:** Binary Indexed Tree, low bit, point update, prefix query
- **Problem:** Maintain an array under two operations: `1 i delta` adds `delta` to element `i`; `2 l r` asks for the sum from `l` to `r`, inclusive. Indices are 1-based.
- **Input:** `N Q`; then `N` initial values; then `Q` operations in the format above.
- **Output:** One line for every type-2 operation.
- **Constraints:** `1 <= N,Q <= 200000`; initial values and deltas have absolute value at most `10^9`; all sums fit in signed 64-bit range.
- **Sample 1:** Input `5 4`, array `1 2 3 4 5`, operations `2 2 4`, `1 3 5`, `2 2 4`, `2 1 5`; output `9`, `14`, `20`.
- **Sample 2:** Input `3 2`, array `-1 0 2`, operations `2 1 3`, `1 1 4`; output `1`.
- **Target complexity:** Build `O(N)` or `O(N log N)`; each update/query `O(log N)`; extra space `O(N)`.
- **Skill tested:** Implementing a compact indexed tree structure from first principles.

### P62 — Segment Tree: Point Update and Range Minimum

- **Constraints:** `1 <= N,Q <= 100000`; `1 <= L <= R <= N`; `1 <= K <= R-L+1`; `|A[i]| <= 10^9`.
- **Sample 1:** Input `5 3`, array `5 1 4 2 3`, queries `1 5 3`, `2 4 2`, `3 5 1`; output `3`, `2`, `2`.
- **Sample 2:** Input `4 1`, array `8 8 1 1`, query `1 4 3`; output `8`.
- **Target complexity:** Build `O(N log N)`; each query `O(log N)`; memory `O(N log N)`.
- **Skill tested:** Comparing prefix versions of a value-domain segment tree to answer subarray order statistics.

### P76 — Build a Suffix Array

- **Difficulty:** 9/10
- **Concepts:** suffix arrays, sorting ranks, doubling algorithm
- **Problem:** Given a string, output the starting indices of all its suffixes in lexicographically increasing order. Indices are 0-based. The suffix beginning at the final character is included.
- **Input:** One string `S` of lowercase English letters.
- **Output:** `N` space-separated indices forming the suffix array.
- **Constraints:** `1 <= |S| <= 200000`.
- **Sample 1:** Input `banana`; output `5 3 1 0 4 2`.
- **Sample 2:** Input `aaaa`; output `3 2 1 0`.
- **Target complexity:** Time `O(N log N)` with a doubling method and efficient sorting; extra space `O(N)`.
- **Skill tested:** Replacing whole-suffix comparisons with sortable equivalence classes of ranks.

### P77 — Minimum Characters to Append for a Palindrome

- **Difficulty:** 8/10
- **Concepts:** KMP prefix function, string reversal, border matching
- **Problem:** You may append characters to the end of a string, but may not change or prepend any characters. Find the minimum number of characters that must be appended to make the final string a palindrome. You only need to output the count.
- **Input:** One string `S` containing lowercase English letters.
- **Output:** Minimum number of appended characters.
- **Constraints:** `1 <= |S| <= 1000000`.
- **Sample 1:** Input `abac`; output `3`.
- **Sample 2:** Input `racecar`; output `0`.
- **Target complexity:** Time `O(N)`; extra space `O(N)`.
- **Skill tested:** Finding the longest palindromic suffix using a prefix-function construction.

### P78 — Convex Hull: Boundary Vertex Count and Perimeter

- **Difficulty:** 9/10
- **Concepts:** computational geometry, monotonic chain, cross product
- **Problem:** Given a set of 2D integer points, construct the convex hull. Remove duplicate points and do not include points that lie strictly inside a straight hull edge. Output the number of hull vertices and the perimeter of the convex polygon. For one or two unique points, define the perimeter as `0` or twice the distance between the two points, respectively.
- **Input:** First line `N`; next `N` lines contain integer coordinates `x y`.
- **Output:** Hull vertex count on the first line; perimeter on the second line, rounded to exactly two digits after the decimal point.
- **Constraints:** `1 <= N <= 200000`; `|x|,|y| <= 10^9`.
- **Sample 1:** Input `4`, points `(0,0) (0,1) (1,0) (1,1)`; output `4` and `4.00`.
- **Sample 2:** Input `3`, points `(0,0) (1,0) (2,0)`; output `2` and `4.00`.
- **Target complexity:** Time `O(N log N)`; extra space `O(N)`.
- **Skill tested:** Sorting points, using cross products to remove non-hull turns, and handling collinear degeneracy.

### P79 — 2D Fenwick Tree: Point Add and Rectangle Sum

- **Difficulty:** 9/10
- **Concepts:** two-dimensional BIT, inclusion–exclusion, matrix indexing
- **Problem:** Maintain an initially zero `R x C` matrix. Operation `1 x y delta` adds `delta` to cell `(x,y)`. Operation `2 x1 y1 x2 y2` asks for the sum of the inclusive rectangle with opposite corners `(x1,y1)` and `(x2,y2)`.
- **Input:** `R C Q`; then `Q` operations as described. Coordinates are 1-based and rectangle coordinates are valid.
- **Output:** One line for every type-2 operation.
- **Constraints:** `1 <= R,C <= 2000`; `1 <= Q <= 200000`; `|delta| <= 10^9`; answers fit in signed 64-bit range.
- **Sample 1:** Input `3 3 4`, operations `1 1 1 5`, `1 2 2 3`, `2 1 1 2 2`, `2 2 2 3 3`; output `8`, `3`.
- **Sample 2:** Input `2 2 2`, operations `1 2 2 -4`, `2 1 1 2 2`; output `-4`.
- **Target complexity:** Each point update and rectangle query `O(log R * log C)`; extra space `O(RC)`.
- **Skill tested:** Extending prefix-sum data structures to two dimensions and applying four-prefix inclusion–exclusion.

### P80 — Heavy-Light Decomposition: Dynamic Tree Path Sum

- **Difficulty:** 10/10
- **Concepts:** tree decomposition, heavy-light decomposition, segment tree, LCA path splitting
- **Problem:** You are given a tree with a value on every vertex. Support two operations: `U v x` assigns value `x` to vertex `v`; `Q u v` asks for the sum of values on the unique simple path from `u` to `v`, including both endpoints. Updates and queries are online.
- **Input:** `N Q`; then `N` vertex values; then `N-1` undirected edges; then `Q` operations.
- **Output:** One path sum for each `Q` operation.
- **Constraints:** `1 <= N,Q <= 200000`; initial and updated values have absolute value at most `10^9`; every path sum fits in signed 64-bit range.
- **Sample 1:** Input `5 4`, values `1 2 3 4 5`, edges `1 2`, `1 3`, `2 4`, `2 5`, operations `Q 4 3`, `U 2 10`, `Q 4 5`, `Q 1 3`; output `10`, `19`, `4`.
- **Sample 2:** Input `1 2`, value `7`, operations `Q 1 1`, `U 1 -2`; output `7`.
- **Target complexity:** Preprocessing `O(N)` or `O(N log N)`; each update/query `O(log^2 N)`; extra space `O(N)`.
- **Skill tested:** Decomposing a tree path into a logarithmic number of heavy-chain intervals and querying them with a segment tree.
